## Approved Reader-Facing Term

When the book measures the estimated derivative field generated by a *dhātuḥ*,
the approved term is ***generative reach***.

This is a measured variable, not a universal replacement for every use of
*productive*. Other occurrences describe sound contrasts, grammatical
resources, new composition, language contact, or an ordinary action. Those
need concrete wording suited to their context.

## Classification Key

| Code | Meaning | Default treatment |
|---|---|---|
| **GR** | Quantified derivative count or statistical variable | Replace reader-facing *productivity* with ***generative reach*** |
| **CV** | Corpus valency, reactivity, or number of recorded combinations | Use ***combinatorial reach*** or the exact measured quantity; do not merge it silently with GR |
| **LW** | Laukika/worldly use and new composition | Name *laukika use*, *new composition*, or the concrete act |
| **GF** | Reusable grammatical form, affix, or paradigm | Say that speakers can use it to generate new words or forms |
| **SF** | Reusable sound distinction or coordinate | Use *independent contrast*, *reusable coordinate*, or *complete sound-series* |
| **VM** | Vivimorphosis in a receiving language | Say that the received element generates words, compounds, or new forms there |
| **GA** | General generative ability of an architecture or constructed language | Use *generative architecture*, *generative capacity*, or a concrete description |
| **PL** | Ordinary nontechnical prose | Replace with the intended ordinary action |
| **IR** | Internal analysis name, script, CSV, file path, or exact source title | Retain for reproducibility unless a separate migration is approved |
