## Pass 2 — Terminology

The terminology pass settled the central comparison:

> Sanskrit uses one language architecture under two different permissions. The
> vaidika domain preserves a read-only reference corpus. The laukika domain
> provides a write-enabled generative space.

The permission applies to content. It does not create a Vedic engine and a
laukika engine.

The draft now distinguishes:

- *vaidika / laukika*: broad civilizational domains;
- *chandasi / bhāṣāyām*: Pāṇinian operational scopes;
- style: differences among corpora and authors;
- mode: a way an operation is deployed, never a chronological stage.

The first explanation develops the computer comparison in full. Later
deployments can use **read-only reference corpus** and **write-enabled generative
domain** without repeating the complete explanation.

## Pass 6 — Entropy, Asuric Assault, and Plain Language

The close now separates:

- entropy, which alters transmission without requiring an antagonist;
- asuric assault, which deliberately destroys, captures, shames, displaces, or
  obscures the calibrant.

The two permissions counter those threats differently:

- vaidika preservation keeps the reference beyond revision;
- laukika generation keeps Sanskrit useful in changing circumstances;
- distributed teaching and analysis prevent either function from becoming the
  property of one apex.

The prose pass removed stacked short declarations, vague abstract transitions,
academic caution, and compressed mechanism statements. Existing book refrains
were not touched because this is a new working draft rather than a manuscript
revision.
