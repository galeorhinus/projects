# Canon / Canonical Vocabulary Audit

**Status:** Implemented in live manuscript sources. Remaining uses of *canon* / *canonical* are retained only where they describe pyramid, Abrahamic, institutional, technical, filename, or source-title contexts.

**Scope scanned:** live manuscript Markdown under `atomicSanskrit/`, current reference files, and `as_endnotes.md`. Generated `build/`, archived drafts, figure workflow notes, and most planning notes were excluded from replacement decisions because they are not reader-facing prose.

**Decision rule:** Do not use *attested* as a replacement. For Sanskrit / Hindu-continuum material, prefer **listed**, **documented**, **received**, **standard**, **operational**, **lineage-preserved**, **reference**, **working**, or **established** depending on context. Keep **canon / canonical** when the sentence is describing pyramid systems: church canon, Biblical / Quranic / Masoretic / ecclesiastical authority, textbook canons, academic canons, and institutional custody.

## Replacement Guide

| Current use | Preferred direction |
|---|---|
| `canonical` = source of truth for internal project files | `reference`, `working reference`, `source-of-truth`, or `live reference` |
| `canonical` = Sanskrit / vyākaraṇa / paramparā object | `received`, `documented`, `standard`, `lineage-preserved`, or `operational` |
| `canonical` = repeated example in the book | `standard example`, `listed example`, `documented example`, `reference example`, or phrase the source directly |
| `canonical` = source enumerates a finite set | `listed`, `source-listed`, or name the source directly |
| `canonical` = inventory used for analysis | `operational inventory`, `working inventory`, or `standard inventory` |
| `canonical` = pyramid / Abrahamic / institutional text | keep `canon` / `canonical` |
