# Orthodoxy to Dogma Replacement Policy

This file is the working source of truth for replacing *orthodoxy* vocabulary across *Atomic Sanskrit*. The issue is not only wording. The word *orthodoxy* frames the fight as an inside-the-pyramid doctrinal dispute. The book prosecutes the pyramid from outside.

## Replacement Table

| Current use | Preferred replacement | Other good options | Notes |
|---|---|---|---|
| `orthodoxy` | `dogma` | `doctrine`, `pyramid's doctrine` | Use `dogma` when prosecuting; use `doctrine` when explaining structure. |
| `progressive orthodoxy` | `progressive dogma` | `linear-progress dogma` | Use `linear-progress dogma` when the time-axis matters. |
| `foundational orthodoxy` | `foundational dogma` | `origin dogma`, `corridor-of-origin dogma` | `foundational dogma` is the clean default. |
| `Western philological orthodoxy` | `Western philological dogma` | `philological machinery` | Use `dogma` for belief-content; `machinery` for institutions and processes. |
| `the orthodoxy claims/says` | `the dogma requires` | `the machinery repeats`, `the pyramid insists` | Pick the replacement by the sentence's actor. |
| `orthodox account` | `pyramid's account` | `pyramid's version`, `manufactured account`, `official pyramid account` | Avoid `standard account`, `textbook account`, and `modern story`. |
| `orthodox scholar/linguist` | `certified intellectual` | `credentialed carrier`, `pyramid-trained scholar`, `academy-certified expert` | Use based on desired sting. |
| `orthodox defense` | `pyramid's defense` | `dogmatic defense`, `institutional defense` | Use `pyramid's defense` when the actor matters. |
| `orthodox framework` | `pyramid's framework` | `dogmatic frame`, `containment frame` | `containment frame` works when Sanskrit is being boxed in. |
| `orthodox reconstruction` | `pyramid's reconstruction` | `manufactured reconstruction`, `philological reconstruction` | For PIE contexts. |

## Term Roles

- **dogma** = protected belief-content.
- **doctrine** = structured teaching.
- **machinery** = institutions and processes that repeat it.
- **pyramid's account / pyramid's version / manufactured account** = reader-facing story.
- **certified intellectuals** = credentialed carriers below the apex who repeat, translate, popularize, or defend the dogma.
- **pyramid** = total structure.

## Editing Workflow

1. Run `rg -n "orthodox|orthodoxy|orthodoxies" atomicSanskrit`.
2. Classify each use: dogma / doctrine / machinery / account / actor.
3. Do not blind replace.
4. Preserve polemic force.
5. Run a final count and report remaining justified uses.

## Certified Intellectuals

Use **certified intellectuals** selectively. It fits the layer below the real pyramid managers: people with credentials who repeat, translate, popularize, and defend the dogma. Best locations: AP0 rākṣasa-retainer layer, Chapter 3 church-of-progress discussion, Chapter 17 heroic erasure, and Chapter 18 PIE defense.
