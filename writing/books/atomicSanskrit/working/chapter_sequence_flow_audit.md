## Flow Verdict

The current macro-sequence is strong:

1. **Admire and define Sanskrit** before prosecuting the misclassification.
2. **Name the wrong metaphor and its motive** before offering internal testimony.
3. **Recover Sanskrit's self-conception** before moving to physical evidence.
4. **Move from instrument -> field -> grid** before building atoms.
5. **Move from atom -> molecule -> assembly** before discussing preservation.
6. **Move from preservation matrix -> living recitation** before killing PIE.
7. **Kill PIE only after the alternative architecture is fully on the table.**
8. **Close with constructive recalibration rather than only demolition.**

The main risk is not sequence. The main risk is density. The book's flow works if each chapter keeps its own job clean and does not prematurely do the next chapter's work.

## Other Ways To Test The Flow

1. **Question-answer ledger.** Write one question each chapter asks and one answer it gives. If two chapters answer the same question, one is repetitive. If a chapter asks no question, it may be ornamental.

2. **Last-page / first-page handoff.** Read only the last two paragraphs of one chapter and the first two paragraphs of the next. If the transition works there, the chapter boundary is probably sound. If not, add a handoff paragraph rather than moving whole sections.

3. **Part-boundary test.** Each part should have a distinct evidentiary mode: charge, internal testimony, physical evidence, technical evidence, chain of custody, cross-examination, remedy. If a chapter's mode does not match its part, either the chapter or part boundary needs adjustment.

4. **Term-birth audit.** Track where key terms first appear: sonomer, audiograph, calibrant, *dhātuḥ* as atom, *kriyā* as molecule, *vākya* as assembly, heroic erasure, *prakṛti/saṃskṛti/vikṛti*, racial Arya thesis. A term should be introduced before it does heavy work.

5. **Metaphor continuity test.** Check that the book's core metaphors progress rather than collide: courtroom, pyramid/swastika, instrument/field/grid, atom/molecule/assembly, calibration matrix, *pratibimba*. The metaphors should arrive in sequence and then recur only where useful.

6. **Figure-first skim.** Read only the figure captions in order. The captions should tell a compressed version of the book's evidentiary arc. If a figure does not advance that arc, it belongs in an appendix or should be cut.

7. **Claim-escalation test.** The book should not ask the reader to accept the strongest claims too early. Preface can announce; chapters must earn. PIE must die only after the architecture has been built, preserved, and tested.

8. **Opposition-response map.** For each major orthodox objection, mark where the book first answers it and where it later closes it. If the same objection is reopened too often, consolidate.

9. **Blind index-card test.** Put each chapter title and one-sentence job on a card. Shuffle them. If a reader can restore the correct order from the logic alone, the sequence is robust.

10. **Compression pass.** After all chapters are stable, write a 2,000-word version of the whole book. Any chapter that cannot contribute one necessary sentence to that compression is either mis-scoped or unnecessary.
