# Atomic Sanskrit Repetition Audit

**Purpose:** Identify unnecessary repetition inside chapters and across the manuscript without cutting intentional refrains, scale-recurring arguments, or chapter-level hammers.

This file is the control document for the audit. Mechanical scans create suspects; human passes decide whether each repeated idea should be kept, compressed, merged, cut, pointed back, moved to an endnote, or promoted into a named principle.

---

## Decision Labels

Use one label for each finding.

| Label | Meaning |
|---|---|
| `KEEP` | Intentional recurrence; it lands as refrain, bridge, or verdict. |
| `COMPRESS` | Keep the idea but reduce the repeated version to a line or two. |
| `MERGE` | Combine nearby paragraphs that are doing the same work. |
| `CUT` | Remove true repetition that adds no new work. |
| `POINTER` | Replace re-explanation with a forward/back reference. |
| `ENDNOTE` | Move supporting detail out of the body. |
| `PROMOTE` | Turn repeated material into a named principle, boxed passage, or glossary entry. |

---

## Audit Pass Checklist

### Pass 0 — Claim Ledger

Goal: identify the manuscript's recurring core claims and assign each one a job.

- [ ] List core repeated claims.
- [ ] Mark first introduction.
- [ ] Mark main demonstration.
- [ ] Mark later deployments.
- [ ] Mark final verdict / closing use.
- [ ] Identify allowed refrain wording.

### Pass 1 — Mechanical Scan

Goal: produce suspects, not edits.

- [ ] Repeated exact sentences.
- [ ] Repeated paragraph openings.
- [ ] Repeated 8-12 word phrases.
- [ ] Overused hammers.
- [ ] Repeated explanatory blocks by fuzzy similarity.
- [ ] High-frequency terms by chapter.

### Pass 2 — Within-Chapter Audit

Goal: remove repetition inside individual chapters.

- [ ] Ch0 / Preface / Prologue.
- [ ] Ch1-3.
- [ ] Ch4-8.
- [ ] Ch9-12.
- [ ] Ch13-17.
- [ ] Ch18 / Ch19 / Epilogue.
- [ ] Appendices.

For each chapter, ask:

- Does the repeated point appear at the same level of abstraction?
- Does the later version add evidence, scale, consequence, or verdict?
- Could the later version become a one-line pointer?
- Is the repetition a deliberate hammer?
- Should the detail move to an endnote or boxed principle?

### Pass 3 — Cross-Book Audit

Goal: preserve architecture, cut re-explanation.

- [ ] Compare each core claim across chapters.
- [ ] Keep recurrences that occur at new scale.
- [ ] Compress recurrences that only re-explain.
- [ ] Add pointers where the earlier treatment is sufficient.
- [ ] Check that major claims have one clear primary home.

### Pass 4 — Refrain / Hammer Audit

Goal: keep signature lines powerful by preventing overuse.

- [ ] "Pāṇini decoded, not codified."
- [ ] "Sanskrit was engineered. Encoded in the Vedas. Decoded by many. Pāṇini's decoding is the finest."
- [ ] "Calibration, not codification."
- [ ] "*Dhātuḥ* is atom, not root."
- [ ] "Sanskrit is sonomeric before it is audiographic."
- [ ] "The pyramid splits Sanskrit into *prakṛti* before Pāṇini and codification after Pāṇini."
- [ ] "The architecture is fractal."

### Pass 5 — Edit Batches

Goal: apply accepted decisions in controlled batches.

- [ ] Batch A: Preface / Ch0 / Prologue.
- [ ] Batch B: Ch1-3.
- [ ] Batch C: Ch4-8.
- [ ] Batch D: Ch9-12.
- [ ] Batch E: Ch13-17.
- [ ] Batch F: Ch18 / Ch19 / Epilogue.
- [ ] Batch G: Appendices / notes / glossary / TOC.
