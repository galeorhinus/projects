## The rule

**No Ch 0 / AP0 / Prologue / *dhātuḥ*-chapter material gets cut without being logged here.** The restructure dissolves and relocates a lot — AP0 → a crisp Ch 1, the standalone *dhātuḥ* chapter → four homes, the Prologue → the Part I opener — and the tightening will drop paragraphs. Every removed passage is logged below *before* it leaves the source file, so nothing load-bearing vanishes silently and anything cut can be recovered or re-sited.

## How to log an entry

For each removed passage, record: **source** (file + section/line), the **passage** (full text, not a summary), and **disposition** — one of:
- `RELOCATED → <destination>` — moved verbatim/edited into another chapter.
- `PARKED` — not currently placed; candidate for re-siting (say where it might go).
- `SUPERSEDED` — replaced by better prose elsewhere (name it); kept here only for recovery.
- `CUT` — genuinely dropped; reason required.

Nothing is deleted from this log until the restructure is complete and the author signs off.
