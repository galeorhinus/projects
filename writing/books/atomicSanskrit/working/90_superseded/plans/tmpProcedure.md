Create:

`atomicSanskrit/working/80_completed/audits/repetition_audit_2026-05-31.md`

Use it as the control document, not just notes. It should track the pass, status, findings, and edit decisions.

**Procedure**

1. **Pass 0 — Claim Ledger**
   Identify the book’s repeated core claims and assign each one a job:
   - first introduction
   - main demonstration
   - later deployment
   - final verdict

   This prevents accidental cutting of intentional refrains.

2. **Pass 1 — Mechanical Scan**
   I run exact/fuzzy scans for:
   - repeated sentences
   - repeated paragraph openings
   - repeated 8–12 word phrases
   - overused hammers
   - repeated explanatory blocks

   Output goes into the audit file as suspects, not automatic cuts.

3. **Pass 2 — Within-Chapter Audit**
   Chapter by chapter:
   - repeated explanation inside the same chapter
   - paragraph doing the same work twice
   - places where one version can become a pointer
   - places where a repeated idea should be promoted into a boxed principle

4. **Pass 3 — Cross-Book Audit**
   Same idea across chapters:
   - keep if the idea is now appearing at a new scale
   - compress if it is re-explaining
   - cross-reference if earlier explanation is sufficient
   - move to endnote if it is support, not argument

5. **Pass 4 — Refrain/Hammer Audit**
   Separately review intentional repeated lines:
   - “Pāṇini decoded, not codified”
   - “Sanskrit was engineered…”
   - “calibration, not codification”
   - “dhātuḥ is atom, not root”

   These should recur, but only where they land.

6. **Pass 5 — Edit Batches**
   Make edits in batches:
   - Ch0–3
   - Ch4–8
   - Ch9–12
   - Ch13–17
   - Ch18, epilogue, appendices

   After each batch, update the audit file.

**Decision Labels**

Each finding gets one label:

- `KEEP` — intentional recurrence
- `COMPRESS` — shorten to a line
- `MERGE` — combine nearby paragraphs
- `CUT` — true repetition
- `POINTER` — replace with chapter/section reference
- `ENDNOTE` — move supporting explanation out of body
- `PROMOTE` — turn repeated idea into a named principle/boxed passage

That gives us discipline. We won’t flatten the book’s rhythm, but we’ll remove places where the reader is being told the same thing at the same level twice.
