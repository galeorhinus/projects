# समासः Type Inventory

Pinned Vidyut 0.4.0 exposes **8** compound types: `Avyayibhava`, `Tatpurusha`, `Karmadharaya`, `Dvigu`, `Ekadeshin`, `Bahuvrihi`, `Dvandva`, `SamaharaDvandva`.

No type becomes a multiplier by name alone. Each admitted compound must retain its members, intended relation, member count, and derivational depth.
