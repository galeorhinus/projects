# Word-Meaning Identity Review

## Result

Reviewed **221 groups / 483 source entries**. 79 groups support consolidations, 105 retain different words or meanings, and 37 remain open.

**2,739 → 2,653 provisional assignments:** 86 duplicate assignments consolidated. No source row or original gloss was deleted. No new meaning, prefix, derivation, or inflection was added.

Each batch takes its declared number of unreviewed groups in the exact-citation ledger's SLP1 sort order. No selection by expected count reduction. Batches 1 and 2 contain ten groups each; Batches 3 through 8 contain thirty each; Batch 9 contains the final twenty-one.

Merge only the documented shared word-meaning. Preserve source rows, grammatical class, markers, alternate readings, and other meanings. A cross-class base merge does not collapse all derived formations or authorize every operation.
