# तिङन्त Pass 1: लकार Boundary

The लौकिक capacity uses ten लकाराः. वैदिक लेट् remains in its own domain.

| लकारः | Plain function | Disposition |
|---|---|---|
| लट् (laṭ) | present | counted_laukika |
| लिट् (liṭ) | perfect past | counted_laukika |
| लुट् (luṭ) | periphrastic future | counted_laukika |
| लृट् (lṛṭ) | future | counted_laukika |
| लोट् (loṭ) | command or request | counted_laukika |
| लङ् (laṅ) | imperfect past | counted_laukika |
| विधिलिङ् (vidhiliṅ) | possibility, prescription, or intention | counted_laukika |
| आशीर्लिङ् (āśīrliṅ) | blessing or wish | counted_laukika |
| लुङ् (luṅ) | aorist past | counted_laukika |
| लृङ् (lṛṅ) | conditional | counted_laukika |
| लेट् (leṭ) | Vaidika verbal resource | withheld_vaidika_domain |

The count uses कर्तरि प्रयोग. Each लकार first contributes one third-person singular citation coordinate and later expands to nine person-number cells. The two पद series remain alternative forms within those cells.
