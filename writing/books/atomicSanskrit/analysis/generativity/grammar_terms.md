# Grammatical Terms Used in the Generativity Analysis

Use the Sanskrit grammatical category first and retain the English term as a short gloss. Stable machine identifiers remain ASCII so that scripts and historical results do not break.

| Sanskrit category | English gloss |
|---|---|
| धातुः (*dhātuḥ*) | verbal atom or verbal base |
| प्रातिपदिकम् (*prātipadikam*) | nominal base |
| उपसर्गः (*upasargaḥ*) | preverb or prefix |
| प्रत्ययः (*pratyayaḥ*) | affix |
| सनादिप्रत्ययः (*sanādipratyayaḥ*) | one of the suffixes that creates a derived धातुः (*dhātuḥ*) |
| णिजन्त (*ṇijanta*) | causative formation |
| सन्नन्त (*sannanta*) | desiderative formation |
| यङन्त (*yaṅanta*) | repeated or intensive formation |
| यङ्लुगन्त (*yaṅluganta*) | यङन्त (*yaṅanta*) formation in which *luk* removes यङ् (*yaṅ*) |
| नामधातुः (*nāmadhātuḥ*) | denominative or noun-derived verbal atom |
| कृदन्तम् (*kṛdantam*) | primary formation from a धातुः (*dhātuḥ*) |
| तद्धितान्तम् (*taddhitāntam*) | secondary formation from a प्रातिपदिकम् (*prātipadikam*) |
| स्त्रीप्रत्ययः (*strīpratyayaḥ*) | feminine-forming affix |
| अव्ययम् (*avyayam*) | indeclinable |
| समासः (*samāsaḥ*) | compound |
| तिङन्तम् (*tiṅantam*) | inflected verbal form |
| सुबन्तम् (*subantam*) | inflected nominal form |
| लकारः (*lakāraḥ*) | tense or mood category |
| पुरुषः (*puruṣaḥ*) | grammatical person |
| वचनम् (*vacanam*) | grammatical number |
| पदम् (*padam*) | *parasmaipada* or *ātmanepada* series |
| प्रयोगः (*prayogaḥ*) | active, passive, or impersonal construction |
| लिङ्गम् (*liṅgam*) | grammatical gender |
| विभक्तिः (*vibhaktiḥ*) | case category |

When a sentence would become crowded, use the Sanskrit term by itself after the first pairing in that section. Do not replace a precise Sanskrit category with a broader English label when the Sanskrit category is already known.
